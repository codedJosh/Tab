### Simulation checklist used for this pass
1. Create tournament.
2. Add institutions, teams, speakers, judges.
3. Generate round draw.
4. Publish draw.
5. Submit partial then full ballots.
6. Confirm round lifecycle and ballot progress state.
7. Confirm standings publication state toggle.
8. Confirm control-room next-required-action updates.
